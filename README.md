# NIRUX wallpapers

Optional **4K and 8K wallpapers** for the NIRUX desktop themes. The default
**Noir** wallpaper is shipped with NIRUX itself; this repository holds the
optional themes and the Carl Larsson / Erik Satie colour variants.

The images are published as **GitHub release assets**, not committed to the Git
history. NIRUX downloads only the theme or pack the user asks for and verifies
the size and SHA-256 checksum before installing it.

## Release assets

Each theme archive contains its 4K and 8K PNG. The two `-extras` archives contain
the red, blue, green and noir colour variants for that theme.

| Asset | Contents |
|---|---|
| `nirux-wallpaper-nord.tar.xz` | Nord, 4K + 8K |
| `nirux-wallpaper-satie.tar.xz` | Erik Satie, 4K + 8K |
| `nirux-wallpaper-carl-larsson.tar.xz` | Carl Larsson, 4K + 8K |
| `nirux-wallpaper-forest-vigil.tar.xz` | Forest Vigil, 4K + 8K |
| `nirux-wallpaper-blood-of-urdr.tar.xz` | Blood of Urðr, 4K + 8K |
| `nirux-wallpaper-root-and-stone.tar.xz` | Root and Stone, 4K + 8K |
| `nirux-wallpaper-blue-horizon.tar.xz` | Blue Horizon, 4K + 8K |
| `nirux-wallpaper-the-norns.tar.xz` | The Norns, 4K + 8K |
| `nirux-wallpaper-winter-nights.tar.xz` | Winter Nights, 4K + 8K |
| `nirux-wallpaper-carl-larsson-extras.tar.xz` | Carl Larsson colour variants, 4K + 8K |
| `nirux-wallpaper-satie-extras.tar.xz` | Erik Satie colour variants, 4K + 8K |

`SHA256SUMS` is attached to the release. NIRUX pins both the release and each
asset hash; a new wallpaper revision must use a new release/tag rather than
replacing an existing asset.
